# DIM Experiment No. 08 – AI-Based Customer Persona Generation

Digital Marketing (KJSSE/IT/LYBTech/Sem-VII/DIM/2026-27). The experiment segments the audience of **ClimaSense AI**, the climate-intelligence / heatwave-monitoring website in the parent repository, into data-driven customer personas using K-Means clustering (pandas, scikit-learn, matplotlib).

> **The data is synthetic.** ClimaSense AI is a frontend-only demo site with no real customers or analytics, so `data/customers.csv` is generated by `scripts/generate_dataset.py` (`np.random.default_rng(42)`, 818 rows). It imitates visitors and subscribers in the dashboard cities (Mumbai, Delhi, Pune, Ahmedabad, Bengaluru), contains four hidden audience groups, and deliberately includes duplicates, missing values and inconsistent spellings for the cleaning step.

This folder is self-contained and independent of the React app. Everything is managed with [`uv`](https://docs.astral.sh/uv/) in a local `.venv`.

## Run it

Run all commands from inside this `digital-marketing/` folder.

```bash
uv sync                                        # install dependencies from pyproject.toml / uv.lock
uv run python scripts/generate_dataset.py      # (re)create data/customers.csv
uv run jupyter lab                             # open notebooks/expt_08_persona_generation.ipynb

# or execute the whole notebook headlessly and save every output:
uv run jupyter nbconvert --to notebook --execute --inplace notebooks/expt_08_persona_generation.ipynb
```
